About Zero Tic‑Tac‑Toe
  • Each side has two 1s, two 2s, two 3s.
  • Overwrite only your opponent with a strictly higher value. Never overwrite yourself.
  • Win is a 3‑in‑a‑row by owner (values can differ).

1) Structural model (dynamic game)

State \(s\): board configuration + inventories + player to move (finite horizon \(t=0,\dots,12\)).

Actions \(a\in A(s)\): pick a value \(v\in\{1,2,3\}\) you still have and a cell \(i\) that is empty, or contains an opponent tile with smaller value (self‑overwrite is forbidden).

Transition \(s' = T(s,a)\): deterministic placement (with overwrite if allowed) and player switch.

Per‑period utility \(u_{\theta}(s,a)\): parameterized. At terminal states give \(+1/-1/0\) (win/loss/draw). You can add tastes for patterns, e.g. \(\\theta_c\)[center], \(\\theta_{crn}\)[corner], \(\\theta_b\)[blocking], \(\\theta_f\)[forking], …

Add i.i.d. Type‑I extreme value shocks \(\\varepsilon_a\) to get a **logit/quantal‑response** choice model.

Objective: Markov strategy maximizing (optionally discounted) expected payoff with discount \(\\beta\).

Logit Bellman equation
\[ V_t(s) = \\gamma + \\log \\sum\_{a\\in A(s)} \\exp\\big( u_{\\theta}(s,a) + \\beta\\, V\_{t+1}(T(s,a)) \\big) \]
Conditional choice probabilities (CCPs)
\[ P\_{\\theta}(a\\mid s) = \\frac{ \\exp\\big( u_{\\theta}(s,a) + \\beta\\, V\_{t+1}(T(s,a)) \\big) }{ \\sum\_{a'} \\exp\\big( u_{\\theta}(s,a') + \\beta\\, V\_{t+1}(T(s,a')) \\big) } \]

2) What you estimate

Given a dataset of human games \\(\\{(s_i, a_i)\\}\\), the **log‑likelihood** is

\[ \\ell(\\theta) = \\sum\_i \\log P\_{\\theta}(a\_i \\mid s\_i) \]
  • If utilities only appear at terminal nodes (win=1, loss=-1, draw=0) and there are no tastes, you mainly estimate an **error/temperature** parameter and optionally \(\\beta\).
  • With features (center/corner/block/fork, etc.), you **recover human heuristics** \(\\theta\\) plus noise.

3) Solution / estimation routes

  • Direct MLE (solve DP inside): For each \\(\\theta\\), do backward induction to get \\(V\\) and CCPs, compute \\(\\ell(\\theta)\\), optimize (e.g., BFGS).
  • CCP (Hotz–Miller): Estimate empirical \\(\\widehat{P}(a\\mid s)\\), invert to choice‑specific value indices, then map to \\(\\theta\\) via regression/moments.
  • NPL (Aguirregabiria–Mira): Iterate between policy/value given \\(\\theta\\) and updating \\(\\theta\\) to fit observed CCPs.
  • MPEC: Maximize \\(\\ell(\\theta,P,V)\\) **subject to** Bellman/CCP constraints (good for small state spaces).

4) Identification & interpretation

  • With perfect information and known terminal payoffs, the minimax policy is known; structural estimation measures **deviations from optimality** and infers heuristics \\(\\theta\\).
  • Finite horizon & deterministic transitions avoid multiplicity; **latent classes** can capture novice vs expert.
  • **Quantal response equilibrium (QRE)** in this finite game is a special case of the logit model.

5) Why do this?

  • Benchmark: verify CCP/NPL/MPEC implementations on a fully enumeratable game.
  • Inverse RL, in miniature: recover human valuation of patterns (center vs corner, blocking urgency).
  • Teaching: ideal sandbox for dynamic discrete choice with terminal utilities.
